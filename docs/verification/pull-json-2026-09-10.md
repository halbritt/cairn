# Structured CLI pulls — 2026-09-10

`agent pull` and `agent pull-evidence` accept their existing expansion JSON on
stdin when no trailing arguments are supplied. A caller can pass a search entry's
`pull_arguments` directly to `agent pull`. See [usage](../index-and-pull.md).

During native integration maintenance, sending that object to `pull` failed;
the documented JSON operation was `expand`. This change removes that naming
distinction for callers. It is a usability extension to the old contract.

The change reuses bounded JSON handling in `cmd/cairn/agent.go`. Any trailing
argument selects the existing shell parser. The API still validates the supplied
request, including its identity and optional byte span; JSON input does not
generate a new retry UUID. No server upgrade is required.
