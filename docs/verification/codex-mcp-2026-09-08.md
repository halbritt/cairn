# Native Codex MCP connection

Codex CLI 0.153.4 connects to the existing Cairn stdio server and retrieves a
saved lesson through its native MCP client. This adds a verified connection
for another harness without changing Cairn's API or adding a model invocation.
It does not establish an independently solved task or memory benefit.

The probe launched a separate Codex app-server with invocation-only configuration
and an ephemeral thread. Its configured MCP inventory contained exactly one
server and the three permitted retrieval tools: `cairn_search`, `cairn_pull`,
and `cairn_pull_evidence`. Apps and plugins were disabled for the probe. No
`turn/start` request was sent; the client explicitly called the native
`mcpServer/tool/call` endpoint for search and pull.

The search used a new task/run scope and returned the operational scratch-permission
lesson saved earlier through the agent CLI. The pull returned the same record
version and exact body, still ordinary A testimony. Connection paths identify
the existing hosted agent profile; the server owns the fixed repository/task/run
scope and the Unix API owns authorization and destination filtering. No token
contents or database credentials were put into the client configuration.

A separate `codex mcp get --json` check resolved the equivalent command, arguments
and tool filter supplied through `-c`. No user configuration file was edited.
The [configuration example](../mcp.md#codex-example) uses that verified shape.
Codex's [MCP configuration documentation](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)
and [app-server reference](https://learn.chatgpt.com/docs/app-server) describe the
upstream interfaces; the installed binary's generated schemas supplied the exact
request fields used in this probe.

[Verification metadata](codex-mcp-2026-09-08.json) retains hashes and private
source/result paths. Raw note bodies and identifiers remain outside Git. This
is client-driven protocol verification, not a delegated model task, native
resume/compaction handling, process-outcome association, or a comparison of
harness effectiveness. The running Striatum comparison was unchanged.
