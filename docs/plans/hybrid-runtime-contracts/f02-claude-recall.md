This unit ports callable Claude SessionStart and UserPromptSubmit recall into
the private Go Memory entry, using the authenticated local API client. Its
prepared base is `2f2ec3fbc76d0d1824acf7df29919828e93ebfa3`, which joins main
`2aaf9f0382e9602e4cf412122fb13933e4533911` with the named, not yet accepted R1
construction dependency `dd10fd94`. Foundation owns dependency reconciliation,
independent review, integration, push and cleanup.

The first checkpoint admits only the receipt-selected unbound Claude
`agent_tools` Start/prompt cells. Complete receipt, immutable closure, executing
image, derived launcher, original 13-second deadline, configuration pins and
every selected profile's unbound claim remain checked. No binding is stripped.
Claude tools and capture remain refused by this unbound entry; other harness
paths retain their existing dispatch. The new Claude caller reaches the actual
ordinary recall body and shared memory client rather than declaring an unused
handler or changing public/staged selection.

The initial two test methods execute four actual Python/checked-Go process
pairs. Source accepts positive Start/prompt recall and produces the fixed
two-line ValueError diagnostic for a retained quoted NUL query. Before this
change, Go refused all four at compatibility preflight. That RED is retained
in `claude1374-unbound-red.log` and its isolation receipt. The tests preserve
complete state, streams and API request comparisons; the service alone is a
local fixture. Constructed receipt/profile inputs are not recorded native
writer evidence or authority.

Claude-specific required Start refusal are the next part of this same unit.

not Codex turn semantics. This checkpoint does not claim those cells or whole
