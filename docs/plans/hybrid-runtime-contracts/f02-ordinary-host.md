# F02 ordinary memory host

The private image accepts `cairn-lifecycle memory --config PATH`, with one
normalized JSON event on stdin. Shell is a transport for that invocation.
This entry does not enable the separately disabled public lifecycle command.

The reached body uses authenticated `localapi`/`memoryclient` search and the
shared eager candidate, whole read and span helpers. `RunStart` and existing
candidate helper signatures remain unchanged. Scope defaults to the supplied
harness/session. Source admission, privacy/environment checks, session state and
nonblocking lock, required selection, context fitting and receipt accounting
execute before output. Non-Codex recall creates no Codex grant ledger.

Implemented cells are unbound SessionStart/UserPromptSubmit with `agent_tools`,
lexical `ambient` (`semantic_fallback` false), and deferred taskless recall in
either mode, for Source-shaped OpenCode (`ses_...`) and Agy (UUID) identities.
Missing `recall_mode` selects ambient. Agent-tools semantic search uses actual
SDK discovery and entities without Codex's native-turn gate. The five/eleven
second recall deadline starts at recall entry and respects any earlier enclosing
context deadline. Actual best-effort recall observations run after releasing the
session lock. Source's observation harness allowlist excludes Agy; no observation
is invented for that manually supplied identity.

OpenCode's current plugin emits recall at SessionStart/UserPromptSubmit and
capture at PreCompact/SessionEnd. Agy currently has coordination hooks and
ordinary MCP memory tools, with no installed ordinary lifecycle memory hook
(`release.md` REL-FRESH). Direct normalized Agy process coverage does not
establish an installed hook. No Agy hook or adapter is added here.

The optional invocation trace follows Source's owner-only directory/file checks,
no-follow opens, nonblocking trace lock, 512-byte line and 8 MiB file limits.
It records actual entry/parsed/exit metadata; dropped observations remain unknown.
OpenCode's non-UUID session label is omitted from this trace, as in Source.
Unexpected public process faults return one, including a fault while writing the
fixed panic diagnostic. No panic is promoted to required-context exit two.

The new process corpus uses the actual retained Source bundle and its /2 disabled
staging transition against the same synthetic Unix API as Go. Source receives a
pinned disabled opt-in, removes it through its actual activation policy, and then
runs the same effective recall configuration and state seed. There is no mocked
recall/render body. A changed retained bundle is independently refused by Source
before API access. The production Go entry is exercised directly and through a
real shell; an exec trace proves it does not spawn the CLI or Python for recall.

Public compact encoding, cue text, ordered state, record/version/conflict data,
receipts, credit and byte accounting, outcomes, API operations and image identity
remain assertions. Fresh public UUIDv4 pull intents alone receive consistent
aliases for cross-process comparison. Each side's original intent must still
produce its exact internal UUIDv5 whole-read request; span UUIDv4s remain unique.
RPC request UUIDs, clock/duration fields, process IDs and invocation UUIDs are
validated and normalized where nondeterministic. Executing Source and Go SHA
claims are separately checked against their actual files. These are fixture
observations, not production store authentication or measured usefulness.

Provider-selected ambient recall, capture and tool observation remain explicit
unavailable cells and must retain their existing Source selection. An opted-in
bound callback is refused before recall: the literal ordinary argv carries no
checked receipt/deadline selection and cannot silently remove a /3 binding.
Enabled Source inbox profiles are Codex/Claude-only; this entry does not claim a
new OpenCode/Agy inbox profile. Existing private activation argv and the inbox
consumer are unchanged. R04 must retain the checked Source route for any cell
outside this implemented set. This is not full F02/R04 or native-host acceptance.
All provider/native C/CPython, production, deployment and campaign holds persist.
