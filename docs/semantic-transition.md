# Semantic transition fixtures and Release handoff

S-05 / CAIRN-328 supplies a disposable transition harness and this runbook.
The controlling requirements are the transition row and
[Packaging, index transition and rollback](plans/hybrid-runtime-contracts/semantic.md#packaging-index-transition-and-rollback).
Release owns installed configuration writes, activation, rollback and retention.
This document grants no production action.

The default executable fixtures use the actual Go indexer, supervisors, combined API
and a private PostgreSQL cluster with pgvector. Their workers are deterministic
Go protocol fixtures with explicitly artificial identities. They test
scheduling, process ownership, source freshness and completion refusal. They
do not execute a Python model, qualify Rust numerics, or accept a Python rollback.
S-04R / CAIRN-355 acceptance, S-04 / R-01 host qualification and the real-worker
matrix below remain prerequisites for full S-05 acceptance.

## Run the disposable fixtures

From a checkout containing this slice:

```sh
python3 -I -B scripts/check_semantic_transition.py \
  --artifact-dir "$HOME/.cache/semantic-transition-run-$(date +%Y%m%dT%H%M%S)"
```

The output path must be new. The host orchestrates the unchanged
`scripts/test_hybrid_runtime_operations.py` wrapper and retains its command,
isolation report, result and artifact archive. Inside that wrapper the harness
builds a race-enabled Go test executable and the real API binary, initializes
a private PostgreSQL cluster with no TCP listener, and runs the selected tests.
Each database is generated by and dropped by its fixture. A normal
`CAIRN_TEST_DATABASE_URL` cannot select a database for these tests: they also
require the harness's owned-cluster marker and exact private socket path.
No installed semantic source, venv, model, native library, service or database
is mounted as a fixture.

`artifacts/tests.jsonl` retains individual Go test results and observations.
`artifacts/report.json` lists the ten matrix cases, all selected passes,
failures/skips, built executable digests and the real-worker qualification
blocker. A skipped case cannot pass the harness. Failures retain their original
logs. PostgreSQL stops on success or failure; the namespace owns any remaining
fixture children. Lease-expiry/backoff fixtures change timestamps only in this
private database so they do not wait two minutes or five minutes. The production
90-second document, two-second retrieval and two-minute lease limits are unchanged.
